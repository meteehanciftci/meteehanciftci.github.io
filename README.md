# Denge

Tablette kullanılan kişisel harcama defteri.

Harcama ekle → kategori seç → ödeme kaynağı seç → kaydet.

Bakiye, borç, gelir veya yatırım uygulaması değildir.

## Çalıştırma

```bash
npm install
npm run dev
```

http://localhost:3000

```bash
npm test
npm run lint
npm run build:apk
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`

applicationId: `com.harcamadefteri.app`  
Sürüm: 2.0 (versionCode 7)

## Kapsam

Kurallar: `AGENTS.md`
