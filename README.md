# Simple Man

Quiet premium editorial site for a personal philosophy of less, better, and lasting.

Live: https://meteehanciftci.github.io/

## Stack

- HTML + CSS + vanilla JS
- GitHub Pages
- No framework

## Structure

```text
/
├── index.html
├── journal/
├── heritage/
├── stoicism/
├── cifl/
├── about/
├── css/style.css
├── js/main.js
├── js/cifl.js
└── favicon.svg
```

## Local

```bash
cd website
python3 -m http.server 8080
```

Open http://127.0.0.1:8080
